# Historical Design Archive

The files in this directory record earlier Orquesta design and implementation work. They are useful for provenance, but they are not current operating authority and should not be treated as instructions for a live Orquesta project.

For current use, start with the repository [README](../../README.md), [START_HERE](../../START_HERE.md), and the canonical skill entrypoint at `orquesta/SKILL.md`. Runtime project truth belongs to that project's `.orquesta/` state.

Old paths, role counts, screenshots, commands, and test results in this archive may have been superseded. Their dates describe when they were written, not current support guarantees.
