# Orquesta Desktop 0.4.0-preview.1

Status: public preview

This release provides the current Windows x64 preview of Orquesta Desktop and the accompanying Codex skill.

## Included

- Project creation and selection.
- Persistent specialist teams and project-owned state.
- Organization map, tasks, records, settings, and project switching.
- Conversations with the orchestrator and specialists.
- User-action and approval surfaces.
- Local-first Windows packaging.
- Installer and portable ZIP distributions.

## Download

Use `OrquestaSetup.exe` for the installer or `Orquesta-win32-x64-0.4.0-preview.1.zip` for the portable build from GitHub Releases.

SHA-256 checksums are published alongside the release assets.

## Current limitations

- Windows x64 only.
- Builds are not code-signed, so Windows may display an unknown-publisher warning.
- Automatic updates are not available yet.
- macOS and Linux packages are not available yet.

## Updating an existing project

Keep the project's `.orquesta/` directory. It contains Orquesta-managed project state.

Back up important projects before trying a preview release. If you use the skill separately, reinstall it from the current repository version rather than merging old skill files by hand.
