# Disposable Support Triage

This fictional project exists only to test whether Orquesta can turn a small brief into delegated work and a reviewed result.

Read `brief.md` and `requests.csv`. Produce `output/triage-report.md`. Do not contact anyone or send the draft responses.

The run is complete only when the report meets `expected-signals.md` and the Orquesta orchestrator has received and accepted the relevant specialist report.
