# Expected Signals

`output/triage-report.md` should:

- Account for every request from `R-101` through `R-108`.
- Give each request a priority, a short reason, and a concrete next action.
- Distinguish facts in the input from assumptions or missing evidence.
- Identify requests that need billing, product, or security judgment.
- Include three concise response drafts for the most urgent requests.
- State that no response was sent externally.

The Orquesta run should also show a real specialist dispatch, a returned specialist report, and an explicit orchestrator acceptance result. A plausible report produced entirely inside the orchestrator is not enough for this test.
